PortfolioHUB 
  Repositório destinado à centralização de projetos acadêmicos e pessoais, servindo como portfólio profissional para a graduação em Ciência da Computação.
 Sobre o Projeto
  Este site foi desenvolvido para consolidar minha presença digital e apresentar meus trabalhos de forma organizada. A página foi construída em HTML e está hospedada através do GitHub Pages. 
 Tecnologias e ProcessosDesenvolvimento: Criação de interface responsiva com auxílio de ferramentas de IA para otimização de código.
  Versionamento: Utilização do Git para controle de versões local e integração com o repositório remoto.  
  Hospedagem: Implementação via GitHub Pages a partir do arquivo index.html.  
  Workflow: O fluxo de trabalho seguiu os estágios de Working Directory, Staging Area e Push para o GitHub.
